# Hackcord - Chatcord Hack GUI Client
Created by 2pro12342. 
  
## About 
This is a hack client made in JS for the offline HTML file called "Chatcord". This client has features like; impersonate a user, manage users and execute scripts on them, server utilities, rank management, customizable tags, bot spaming, and more. 
  
## Warnings & Notes 
- Some scripts don't work at all or don't work on your rank level; for example, ban, kick, set rank/role, and others probably wont work if your a normal user. 
- Ban and Kick scripts say who that player was banned by; for example, if user 1 bans user 2 it will say, `user 2 was banned by user 1` as the system message.
- Scripts that doesn't work to my knowledge; disconnecting user (disconnects on your screen), crashing user (broken), Server Bots - Server Tag, Bots time & date joined, Bots Time-out Limit, Disguise as User, and Spy Mode (for user, if enabled for bots it works fine).
- Some scripts don't work globally (only shows for you); Changing Server, Changing User's Name, Wipe Chat History, User Tags, and more.
- The Spam script spams text in all servers you are in. (DMs, Global, Custom Server, etc.)
- To get UID (User's ID), open DevTools `Elements` tab and look for the user's ID.
- `CTRL+H` to toggle hide/show the client. 
  
## Features 
- Impersonate: impersonate a selected user, copying their username and pfp (pfp only works on your screen), disabling turns you back to normal.
- Reload Users: if users don't show in client to manage, this will refresh users connected in the client.
- User Tags (Local): add a custom tag to your username. (adding more tags and fixing it to work globally)
- Wipe Chat History (Local): Wipes the chat's history. (this is good for spammers)
- Force Msg: Select a user and type in the box what you want them to say. ()
- Bots Manager: You can select its name, how many, Time-out Limit (doesn't work), Say Msg, Spawn Bots, and Kill All Bots. (no clue if it also kills other user's bots)
and more!
  
## Installation 
To install the hack GUI, use 1 of these methods: 
  
- Method 1 (JS Bookmarklet):
1. Copy code in `auto-load.js` or in `Hackcord-GUI.js` if raw github is blocked. 
2. Go to `Chatcord`. (install from here and use file urls or an HTML editor)
3. Favorite page, but rename bookmark to `Hackcord GUI`.
4. Set folder to `Other Bookmarks` and paste in your Client JS Code.
5. Click save and click the bookmark on page.
  
- Method 2 (Hackcord already Installed):
1. Download `Hack-GUI-Chatcord.html` and put it into an HTML editor or run it as a file.
